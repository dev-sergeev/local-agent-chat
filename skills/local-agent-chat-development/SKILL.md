# Разработка Local Agent Chat

Перед изменением кода прочитай `../../CONTEXT.md` и строку нужного модуля в
`../../docs/architecture.md`. Если решение меняет устойчивую границу или
инвариант, найди связанный документ в `../../docs/adr/` и обнови его вместе с
кодом.

Используй термины из `CONTEXT.md`. Не создавай второй источник истины для
Model Profile, Agent Mode или активной Agent Memory. Сохраняй согласованность
трёх состояний Revision: Chat History, Agent Memory и Sandbox. Project Skill
может направлять Agent, но не расширяет Agent Mode.

Выбирай тест рядом с изменяемым модулем и сначала воспроизведи наблюдаемое
поведение. Для изменений на границе Chainlit, LangGraph или Deep Agents добавь
интеграционную проверку публичного результата, а для адаптера приватного API —
проверку ожидаемой сигнатуры и явный отказ при несовместимой версии.

Перед завершением запусти целевые тесты, затем полный `pytest -q`,
`ruff check .`, `ruff format --check .` и `git diff --check`. Не публикуй и не
перезапускай приложение, если пользователь не включил это действие в задачу.
