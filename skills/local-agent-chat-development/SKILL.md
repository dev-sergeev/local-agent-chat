# Анализ LocalChat

Работай как read-only reviewer. Изучи доступные исходники, тесты и конфигурацию,
затем верни проверяемые выводы, точный план исправления или предлагаемый patch в
тексте ответа. Ясно отделяй наблюдаемое поведение от предположений и не утверждай,
что изменение применено или тест запущен.

Сохраняй следующие инварианты проекта:

- `ChatBindings` — единственный авторитетный источник Model Profile, Agent Mode
  и активной LangGraph memory thread; UI state и metadata являются зеркалами.
- `CHAT_FILES` читает только Uploaded Files текущего Chat, а `HOST_FILES` —
  доступные процессу абсолютные host-пути. Оба режима имеют ровно `ls`,
  `read_file`, `glob`, `grep` и не предоставляют общую запись или исполнение.
- Project Skills доступны обоим режимам как доверенные read-only инструкции и
  не расширяют их capabilities.
- Revision согласованно возвращает Chat History, Agent Memory, Uploaded Files и
  внутренние артефакты к состоянию перед изменяемым Turn.
- Long-term Memory — общий курируемый Markdown, а Global Memory — поиск по
  активной истории; ни одна из них не заменяет Agent Memory конкретного Chat.

Для дефекта укажи минимальное воспроизведение, вероятную точку нарушения
инварианта и проверку, которая станет красной до исправления и зелёной после.
Для изменения интерфейса перечисли затронутые потребители и миграцию сохранённых
данных. Анализ завершён, когда каждое существенное утверждение связано с
доступным файлом или явно помечено как гипотеза, а предложенная проверка наблюдает
публичный результат.
