# Keep configuration and Chat data together; select native providers explicitly

LocalChat now defaults to the launch directory for `.env` and `models.yaml`, with `.local-agent-chat/` beside them, so each project owns portable Chat History, Agent Memory and Uploaded Files independently of package installation. This supersedes the system-directory defaults in ADR 0012 while preserving explicit paths, process locking and disposable UI workspaces; existing data is moved only by an offline copy, avoiding silent selection or migration of another project’s history. Model Profile identifiers select `openai:` or native `gigachat:` through one construction boundary, with ready GigaChat access tokens and provider-specific inference retries that cannot replay tools or an already-started stream.
