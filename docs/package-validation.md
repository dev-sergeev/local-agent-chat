# Проверка устанавливаемого пакета

Автоматические проверки обновлены 16 сентября 2026 года на Linux/aarch64 с Python 3.12. Пакет `local-agent-chat` версии `0.1.0` собирается в wheel и sdist; `twine check` принимает оба файла. Wheel содержит точку входа `localchat`, приложение, конфигурацию Chainlit, переводы, страницы приветствия, изображения, CSS, JavaScript и примеры настроек.

## Автоматические проверки

- Полный набор: **209 passed, 31 subtests passed**. Предупреждение об устаревающем Pydantic API относится к зависимости `traceloop`.
- `ruff check`, `ruff format --check`, `compileall`, `bash -n`, `git diff --check` прошли.
- CLI проверен на интерактивную и автоматическую настройку, приватные права файлов, буквальное сохранение ключей, отказ от перезаписи конфигурации, приоритет environment и разрешение относительных путей. Help/version не создают служебных файлов. Проверены профили OpenAI/GigaChat, отказ от неизвестного провайдера, перенос относительной конфигурации и независимость двух папок.
- Отдельные проверки запускают настоящий процесс CLI, создают состояние TCP `TIME_WAIT`, затем останавливают сервер через SIGTERM и SIGINT. Данные остаются, временный каталог удаляется; повторный запуск на том же порту разрешён. Занятые порты пропускаются; выбранный сокет передаётся дочернему серверу без освобождения порта. Настоящие HTTP/WebSocket и загрузки проверены со статическим префиксом, `auto` и точным шаблоном VS Code при занятом начальном порте.

`scripts/check_distribution.py` установил wheel с обычными runtime-зависимостями в новый venv вне checkout. Импорт подтвердил загрузку из `site-packages` этого окружения. Через локальную модель-имитатор проверены:

1. Загрузка JS/CSS и UI по полному префиксу прокси.
2. Загрузка `note.txt`, реальный вызов `read_file` и возврат контрольного текста.
3. Пять запросов; редактирование третьего с удалением продолжения и точным соответствием истории UI и runtime SQLite.
4. Остановка, переустановка wheel, перенос всей папки проекта, сохранение конфигурации и возобновление того же чата из другого рабочего каталога.
5. Новый запрос и правка первого; отсутствие поздних запросов в текущем контексте модели.
6. `integrity_check`, `foreign_key_check`, пустые временные архивы Revision, отсутствие ошибок SQLite в логах.
7. Очистка временных файлов при остановке; в папке проекта остаются только `.env`, `models.yaml` и `.local-agent-chat/`, системные пользовательские каталоги не создаются.
8. Отдельная инициализация `gigachat:GigaChat-2`, чтение сохранённого токена из `.env` и вызов `read_file` через нативный GigaChat API.

Эта проверка включена в CI для Python 3.12 и 3.13. Workflow публикации повторяет её для wheel, скачанного из TestPyPI, и сверяет его SHA-256 перед отправкой тех же дистрибутивов в PyPI.

Модульные интеграционные тесты дополнительно проверяют GigaChat streaming с инструментами, суммаризацию, названия чатов, transient HTTP-повторы, таймауты и закрытие потока. После первого фрагмента повтор запрещён; ошибка модели после выполнения инструмента не вызывает инструмент повторно. Учтён nullable счётчик cache-токенов SDK при объединении потоковых фрагментов.

## Браузер

Ручная проверка ниже выполнена 13 сентября 2026 года, до добавления GigaChat; для текущей доработки повторно выполнялись автоматические проверки протокола UI. Установленный wheel запущен из `/tmp` через `localchat run` и открыт в Chromium по публичному маршруту JupyterHub. Через UI загружен файл, выполнены пять запросов, изменён третий запрос и перезагружена страница. Идентификаторы первых трёх запросов сохранились, первые два запроса/ответа не изменились, четвёртый и пятый исчезли из текущей истории. После каждого запроса, редактирования и перезагрузки полные тексты запросов и ответов в UI совпали с SQLite. Необработанных ошибок JavaScript нет.

Во время проверки использовалась управляемая локальная модель, поэтому этот прогон не оценивает качество ответов внешнего LLM-провайдера. Предыдущая проверка реальной модели и глубины 100 запросов описана в [ReAct validation](react-validation.md).

## Исправления, найденные при упаковке

Chainlit завершает процесс через `os._exit()`, поэтому Python-finalizers вокруг его CLI не выполнялись. Теперь родительский процесс владеет временным каталогом и очищает его после завершения дочернего сервера; приложение закрывает свои ресурсы до завершения lifespan Chainlit. Проверка порта использует `SO_REUSEADDR`, чтобы TCP `TIME_WAIT` после штатной остановки не запрещал немедленный перезапуск.

Результат новой проверки wheel и журналы находятся в `/tmp/localchat-wheel-8qxtm2pz`; прежние материалы ручной проверки — в `/tmp/localchat-package-validation-3` и `/tmp/localchat-browser`; они не включаются в Git или дистрибутивы. Тестовые процессы после проверки остановлены. Публикация на внешних индексах требует настройки Trusted Publisher владельцем аккаунтов; локальная сборка и проверка сами по себе не означают публикацию.
