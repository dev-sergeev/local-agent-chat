# LocalChat

Чат с агентом и сохранённой историей. Поддерживаются OpenAI-compatible API и нативные модели GigaChat. Загружайте файлы в диалог: агент может читать их и искать нужные фрагменты. Доступ ограничен файлами этого чата.

По умолчанию ответ приходит целиком, без потоковой передачи. Одновременно выполняется только один запрос. Если модель занята в другом чате или вкладке, дождитесь завершения и отправьте запрос снова. Кнопка Stop отменяет запрос, в том числе ожидание повторной попытки.

В длинном диалоге агент сохраняет недавние сообщения и сводку предыдущего контекста. Полная история остаётся доступна в интерфейсе. Изменение прежнего запроса удаляет последующее продолжение и создаёт новый ответ.
