# Local Agent Chat

Чат с Deep Agent в изолированной песочнице. Прикрепите файлы к сообщению — агент сможет читать и изменять их, запускать Python и shell-команды, а созданные результаты появятся рядом с ответом.

Во время работы раскрывается ход выполнения: файловые операции, shell и Python отображаются отдельными шагами, а итоговый ответ появляется постепенно. Активную задачу можно остановить кнопкой рядом с полем ввода. В настройках чата доступно переключение между краткими и подробными результатами инструментов.

Выберите Model Profile при создании чата. Профиль, история, память агента и файлы сохраняются после перезапуска. Карандаш у пользовательского сообщения создаёт новую активную ветку: память и файлы откатываются, затем агент выполняет изменённый запрос заново.
