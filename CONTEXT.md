# LocalChat

Локальный чат-интерфейс для продолжительной работы пользователя с агентом в среде JupyterHub.

## Language

**Chat**:
Продолжаемый диалог пользователя с агентом, имеющий собственную историю и память.
_Avoid_: Session, conversation

**Turn**:
Один пользовательский запрос и связанный с ним ответ агента.
_Avoid_: Message pair, interaction

**Agent**:
Участник чата, который отвечает пользователю, рассуждает и применяет доступные ему инструменты.
_Avoid_: Bot, assistant

**Sandbox**:
Принадлежащее одному Chat локальное хранилище загруженных файлов и служебных артефактов Agent. Revision откатывает оба дерева. Это граница хранения и отката, а не среда исполнения и не замена внешней изоляции контейнером или VM.
_Avoid_: Workspace, project directory

**Uploaded File**:
Файл, явно переданный пользователем в чат и доступный агенту внутри Sandbox.
_Avoid_: Attachment, workspace file

**Chat History**:
Сохранённые чаты, которые пользователь может вновь открыть после перезапуска приложения.
_Avoid_: Logs, transcript archive

**Agent Memory**:
Состояние агента, необходимое для корректного продолжения конкретного Chat.
_Avoid_: Chat History, context

**Global Memory**:
Доступный Agent по необходимости read-only поиск по актуальным Turn других Chat с ограниченным раскрытием найденного контекста и ссылкой на источник. Revision и удаление Chat немедленно исключают соответствующие Turn; история не добавляется автоматически в каждый запрос.
_Avoid_: Agent Memory, shared context, profile

**Long-term Memory**:
Компактный курируемый набор актуальных устойчивых фактов о Local User, его предпочтениях и проверенных результатах, общий для всех Chat. Он сохраняется независимо от жизненного цикла отдельного Chat и может быть явно исправлен или забыт.
_Avoid_: Agent Memory, Global Memory, Chat History, profile

**Model Profile**:
Выбранная при создании Chat конфигурация модели, не содержащая секретов провайдера. Пока профиль доступен, он неизменяем; удалённый профиль при возобновлении Chat заменяется доступным fallback.
_Avoid_: Provider, model settings

**Agent Mode**:
Выбранная при создании Chat область файлового чтения. `CHAT_FILES` доступен по умолчанию и видит только Uploaded Files текущего Chat, а `HOST_FILES` читает доступные процессу host-файлы по абсолютным путям. Оба режима имеют одинаковые инструменты `ls`, `read_file`, `glob`, `grep` и не предоставляют общего изменения файлов или исполнения. После первого отправленного сообщения Agent Mode неизменяем.
_Avoid_: Model Profile, permissions toggle, version

**Project Skill**:
Версионируемый пакет процедурных инструкций, доступный Agent по необходимости для определённого типа задач. Он общий для всех Chat и обоих Agent Mode, не является Uploaded File и не расширяет область чтения или набор инструментов.
_Avoid_: Prompt fragment, plugin, uploaded instruction

**Revision**:
Замена пользовательского запроса, после которой последующие Turn удаляются, Agent Memory, Uploaded Files и служебные артефакты возвращаются к состоянию перед изменяемым Turn, а Agent заново выполняет изменённый запрос.
_Avoid_: Edit, branch

**Local User**:
Единственный пользователь экземпляра приложения, распознаваемый автоматически без экрана входа.
_Avoid_: Anonymous user, account
