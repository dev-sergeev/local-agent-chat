# Local Agent Chat

Локальный чат-интерфейс для продолжительной работы пользователя с агентом в среде JupyterHub.

## Language

**Chat**:
Продолжаемый диалог пользователя с агентом, имеющий собственную историю и память.
_Avoid_: Session, conversation

**Turn**:
Один пользовательский запрос и связанный с ним ответ агента.
_Avoid_: Message pair, interaction

**Agent**:
Участник чата, который отвечает пользователю, рассуждает и применяет доступные ему инструменты.
_Avoid_: Bot, assistant

**Sandbox**:
Принадлежащее одному Chat локальное рабочее пространство с пользовательскими файлами и служебными артефактами агента. В Extended Agent Mode оно также содержит собственное Python-окружение. Revision откатывает файлы и артефакты, но не пакеты и не изменения произвольных host-файлов. Это не security sandbox: изоляцию должен обеспечить контейнер или VM. Ключи приложения не передаются в environment команд.
_Avoid_: Workspace, project directory

**Uploaded File**:
Файл, явно переданный пользователем в чат и доступный агенту внутри Sandbox.
_Avoid_: Attachment, workspace file

**Chat History**:
Сохранённые чаты, которые пользователь может вновь открыть после перезапуска приложения.
_Avoid_: Logs, transcript archive

**Agent Memory**:
Состояние агента, необходимое для корректного продолжения конкретного Chat.
_Avoid_: Chat History, context

**Global Memory**:
Доступный Agent по необходимости read-only поиск по актуальным Turn других Chat с ограниченным раскрытием найденного контекста и ссылкой на источник. Revision и удаление Chat немедленно исключают соответствующие Turn; история не добавляется автоматически в каждый запрос.
_Avoid_: Agent Memory, shared context, profile

**Model Profile**:
Выбранная при создании Chat конфигурация модели, остающаяся неизменной на протяжении этого Chat и не содержащая секретов провайдера.
_Avoid_: Provider, model settings

**Agent Mode**:
Выбранный при создании Chat набор возможностей Agent. Read-only доступен по умолчанию и читает host-файлы; Extended дополнительно разрешает создание, изменение, удаление и исполнение. После первого отправленного сообщения Agent Mode неизменяем.
_Avoid_: Model Profile, permissions toggle, version

**Revision**:
Замена пользовательского запроса, после которой последующие Turn удаляются, Agent Memory и файлы Sandbox возвращаются к состоянию перед изменяемым Turn, а Agent заново выполняет изменённый запрос. Установленные в окружение пакеты не откатываются.
_Avoid_: Edit, branch

**Local User**:
Единственный пользователь экземпляра приложения, распознаваемый автоматически без экрана входа.
_Avoid_: Anonymous user, account
